# Security Policy

## Supported Versions

We currently support the following versions of Kiv with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability in Kiv, please report it responsibly.

### How to Report

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them by:

1. **Email**: Send details to security@kiv-lang.org
2. **GitHub Security Advisories**: Use the [GitHub Security Advisories](https://github.com/kiv-lang/kiv/security/advisories/new) feature

### What to Include

When reporting a vulnerability, please include:

- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Any suggested fixes or mitigations
- Your contact information (optional, but helpful for follow-up)

### Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial Assessment**: Within 7 days
- **Resolution**: As quickly as possible, typically within 30 days

### Security Team

Our security team consists of:

- Core maintainers
- Security experts from the community
- External security researchers (when needed)

## Security Best Practices

### For Users

- Always use the latest stable version
- Keep your dependencies updated
- Review code before running it
- Use appropriate sandboxing when possible

### For Contributors

- Follow secure coding practices
- Review security implications of changes
- Use tools like `cargo audit` to check for vulnerabilities
- Follow the principle of least privilege

## Security Updates

Security updates will be:

- Released as soon as possible
- Clearly marked in release notes
- Backported to supported versions when feasible
- Communicated through appropriate channels

## Bug Bounty

We currently do not have a formal bug bounty program, but we appreciate security researchers who responsibly disclose vulnerabilities.

## Contact

For security-related questions or concerns:

- **Email**: security@kiv-lang.org
- **GitHub**: [Security Advisories](https://github.com/kiv-lang/kiv/security/advisories)

---

**Thank you for helping keep Kiv and our users safe!**
