# Developer Charter

This is our team covenant. We commit to:

1. **Write an RFC before implementing significant features.**
2. **All user-facing behavior must be tested** (including error messages).
3. **Prefer clarity over cleverness** in code and design.
4. **Document as we go** — no "I’ll write docs later".
5. **Respect the design principles** — if in doubt, refer to `DESIGN_PRINCIPLES.md`.
6. **Be kind and patient** in code reviews and discussions.

Violating this charter doesn’t block PRs, but it triggers a conversation.
