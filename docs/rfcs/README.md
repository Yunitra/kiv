# Kiv RFCs

This directory contains all Request for Comments (RFCs) for Kiv language design.

## How to propose a change

1. Copy `0000-template.md` to `XXXX-your-feature.md`
2. Fill in the template
3. Submit a PR

Accepted RFCs are merged into this directory.
